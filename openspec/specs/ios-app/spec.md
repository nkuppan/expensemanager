# ios-app Specification

## Purpose

How the iOS app links and calls shared Kotlin code: one static umbrella framework (`Shared`,
built by `:shared`), Swift entry points that pass plain values, and an XcodeGen-generated Xcode
project whose build runs Gradle first. Established by the Phase 1 smoke app (change
add-ios-smoke-app); Phase 3's real app builds on the same setup.

## Requirements

### Requirement: One umbrella framework for iOS
The iOS app SHALL link shared Kotlin code through a single static framework named `Shared`,
built by the `:shared` module for `iosArm64` and `iosSimulatorArm64` with iOS 16 as the minimum.
`:shared` SHALL contain only Swift-facing entry points that delegate to shared modules, and no
business logic of its own.

#### Scenario: Building the framework
- **WHEN** `./gradlew :shared:linkDebugFrameworkIosSimulatorArm64` runs on a Mac with Xcode
- **THEN** it produces `Shared.framework` for the simulator

#### Scenario: Android is unaffected
- **WHEN** the Android app is built
- **THEN** no Android module depends on `:shared`

### Requirement: Swift entry points take and return plain values
Entry points exposed to Swift SHALL take and return Swift-friendly values (strings, numbers,
booleans, lists, epoch milliseconds) and SHALL NOT rely on default arguments. Swift formats
them for display.

#### Scenario: Reading a receipt from Swift
- **WHEN** Swift calls `ReceiptReader.shared.read(text:)` with a GPay message for ₹250 paid to
  SWIGGY
- **THEN** it gets amount 250.0, payee "SWIGGY", `isIncome` false and the message's date as
  epoch milliseconds

#### Scenario: Same result as the shared parser
- **WHEN** `ReceiptReaderTest` reads sample receipts on the Android host and the iOS simulator
- **THEN** every field equals the corresponding field of `ReceiptParser.parse` for the same
  text

### Requirement: The smoke app runs shared code on the simulator
The `iosApp/` project SHALL be generated by XcodeGen from `iosApp/project.yml`, build the
framework through Gradle before compiling Swift, and show the receipt parser's result for text
the user enters.

#### Scenario: Building the smoke app
- **WHEN** `xcodegen` runs in `iosApp/` and then `xcodebuild -project ExpenseManagerSmoke.xcodeproj -scheme ExpenseManagerSmoke -destination 'generic/platform=iOS Simulator' build` runs
- **THEN** the build succeeds

#### Scenario: Parsing on the simulator
- **WHEN** the app runs on an iPhone simulator and the "GPay sample" button is tapped
- **THEN** the screen shows ₹250 (as 250.00), payee SWIGGY, Expense, and 7 Nov 2026 7:15 pm in the device's time zone format
